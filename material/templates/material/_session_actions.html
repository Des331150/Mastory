{% comment %} The two buttons that put one session's topic into the student's record, or take it back out of it. Marking is a toggle rather than a switch: pressing the button for the state a topic is already in returns it to untouched, so one control per answer means the student can undo a mark without hunting for a separate control. Which button is lit is read off the session's own state, the same word the panel two lines up prints - not off the topic's columns directly. The session is the row the student is pressing the button on, and one question has one answer: when the page says done, every line on the page that names this session says done, which is what `progress.complete` clearing a skip exists to keep true and not to work around. Neither button says "fail" and neither is styled as one. Skipping is a decision the student is entitled to make and it costs them nothing, so the word on the button is the word they will have to read again tomorrow. {% endcomment %}
